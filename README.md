# 局域网文件传输（Python 版）

无需安装第三方 Python 包，支持浏览器上传、下载、删除文件，并支持指定监听 IP 地址和端口。默认优先使用 `8000` 端口；如果端口被占用，会自动从后续端口中选择可用端口。

## 最简单的启动方式

双击 `run.bat`，按提示输入要监听的 IPv4 地址。直接回车会监听所有本机 IPv4 网卡（`0.0.0.0`），适合一般局域网共享。服务启动成功后会打开独立的局域网访问窗口；按 `Ctrl+C` 停止服务时，该网页窗口也会自动关闭，命令窗口不会继续停留。

启动后，把终端显示的“局域网访问”地址发给同一局域网内的其他设备，在浏览器中打开即可。

也可以直接运行 `dist` 文件夹中的 `LAN传输助手.exe`。EXE 不显示额外的命令窗口，会自动打开独立网页窗口；关闭该窗口会同时结束后台服务。共享文件保存在 EXE 旁边的 `shared` 文件夹中。

## 命令行启动

```powershell
# 指定 IP
python server.py --host 192.168.1.20

# 同时指定端口
python server.py --host 192.168.1.20 --port 8080

# 让系统随机分配可用端口
python server.py --host 0.0.0.0 --port 0

# 必须使用指定端口（被占用时直接退出）
python server.py --host 0.0.0.0 --port 8000 --strict-port

# 启动成功后自动打开局域网访问页面
python server.py --host 192.168.1.20 --open-browser

# 监听所有本机 IPv4 网卡并跳过交互询问
python server.py --host 0.0.0.0 --port 8000

# 指定共享目录
python server.py --host 0.0.0.0 --shared-dir "D:\Videos"
```

注意：`--host` 必须是当前电脑实际拥有的 IP 地址，或使用 `0.0.0.0`。不能填写另一台电脑的 IP。

## Windows 防火墙

第一次启动时，如果 Windows 弹出防火墙提示，请只在可信的“专用网络”中允许访问。若其他设备无法打开页面，请确认：

1. 两台设备在同一局域网或 Wi-Fi 下；
2. 访问的是终端显示的局域网地址，而不是 `127.0.0.1`；
3. 路由器未开启客户端隔离；
4. Windows 防火墙允许 Python 接收入站连接。

## 文件位置

默认共享文件保存在程序目录下的 `shared` 文件夹中。上传同名文件时，新文件会替换旧文件。
