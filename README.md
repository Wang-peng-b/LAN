# 局域网传输（Python 版）

零依赖的局域网文件与文本传输工具。浏览器上传、下载、删除文件，并在手机与电脑之间同步文本。界面为 Apple（iOS）风格，自动适配浅色 / 深色模式。

**页面布局**：顶部导航下用分段 Tab「传输 | 文本」切换主内容——「传输」为上传与文件列表，「文本」为跨设备剪贴板。窄屏默认「传输」，点顶栏「文本」即可发/看剪贴板，文件再多也不必长滚到底；桌面宽屏（≥1024px）左右双栏同时显示传输与文本。

**大文件友好**：上传全程分片 + 断点续传 + 自动重试 + CRC32 校验，理论体积无上限（GB 级实测稳定），中断后重选同一文件自动从断点继续。

## 最简单的启动方式

双击 `run.bat` 即可启动：默认监听所有本机 IPv4 网卡（`0.0.0.0`），无需任何输入。服务启动成功后会自动打开局域网访问页面。

启动前会自动预检端口：默认端口 `8080` 若被占用或落在 Windows 保留端口段，会依次尝试 `8866 / 9000 / 9527 / 18080 / 8000`，取第一个可用端口并在终端提示实际使用的端口。关闭服务（Ctrl+C）时端口随进程自动释放。

启动后，把终端显示的"局域网访问"地址发给同一局域网内的其他设备，在浏览器中打开即可；也可在页面导航点「扫码」展开本机二维码（默认收起），用手机相机扫码打开同一页。地址仍以终端为准，页面不提供复制基址。

**多文件队列 / 取消**：传输区上传入口下方显示队列（文件名、大小、等待中 / 上传中 xx% / 已完成 / 失败 / 已取消）；按选择顺序依次上传，单项可取消（等待中移除，上传中中止会话），支持全部取消与失败重试。

**批量下载 / 删除**：文件列表每行可勾选，标题旁「全选」；选中后出现批量栏「下载选中 / 删除选中」与已选数量（多选≥2 时按钮文案为「打包下载」，一次打成 zip）。删除选中会二次确认。

**可选访问口令**：启动时加 `--pin 1234`，或设置环境变量 `LAN_TRANSFER_PIN=1234`。启用后浏览器先输入口令，通过后写入 HttpOnly 会话 cookie（约 7 天，同浏览器刷新仍有效）。改口令：用新 `--pin` 重启；关闭口令：不带 `--pin` 且去掉环境变量后重启即可。本机 `127.0.0.1` 同样需要口令（无例外）。

**只读访客口令**：再加 `--guest-pin 5678`（或环境变量 `LAN_TRANSFER_GUEST_PIN`）。输入访客口令进入只读模式：可看文件列表、下载、预览、看文本记录、出现在「在线」列表并改自己的昵称；不能上传、删除、发送或删除文本，也不能改别人的昵称（服务端一律 403）。访客口令必须和 `--pin` 一起用，单独设置会启动失败；两个口令相同时按主人处理。

**登录中的设备（会话吊销）**：设了 `--pin` 后，主人在导航「保护」抽屉下半可看到当前已登录的设备（模糊 IP、最近活跃、本机/访客标记），可单个「移出」或「全部退出（含本机）」；被移出的设备约 3 秒内回到口令页，需重新输入口令。访客看不到此区，也无权操作。会话只存在内存里，重启服务后所有设备都需重新登录。

**共享文件自动过期（默认关）**：启动时加 `--ttl-days N`（或环境变量 `LAN_TRANSFER_TTL_DAYS=N`，`N` 为正整数天数）。开启后，共享目录里的文件会按**入库时间**（网页上传完成时写入 `.file-order.json` 的 `ingestedAt`；直接拷进目录的文件无入库记录时回退用修改时间）超过 N 天自动删除；启动时扫一次，之后定时扫。**风险：会真正删除用户文件**，请确认后再开。以下不会被本功能删除：以 `.` 开头的隐藏文件（含 `.file-order.json`、`.clipboard-history.json`）、剪贴板库、以及 `.uploads/` 下未完成的上传分片——后者仍由原来的「超过 7 天未活动」会话清理单独负责，与 `--ttl-days` 互不相干。未设置或 `0` 表示关闭，不会因 TTL 删除任何共享文件。`GET /api/config` 的 `ttlDays` 字段：`0`=关，`≥1`=保留天数。

## 双交付（四文件 zip / Windows 单文件 exe）

本工具始终保留**四文件**交付：`server.py`、`index.html`、`run.bat`、`README.md`。有 Python 的电脑直接解压双击 `run.bat` 即可。

另可选 **Windows 单文件** `lan-transfer.exe`（PyInstaller onefile，须在 **Windows 构建机**用仓库 `packaging/windows/build.bat` 打出；本仓库的 Linux 环境不产正式 exe）。用法与参数和四文件一致（`--pin` / `--guest-pin` / `--ttl-days` / `--port` / `--shared-dir` 等）。

| | 四文件 zip | `lan-transfer.exe` |
|--|--|--|
| 需要本机 Python | 是（3.9+） | 否 |
| 页面 / 业务 | 同版源码 | 同版源码（`index.html` 打进包内） |
| 默认共享目录 | 解压目录旁 `shared/` | **exe 同级** `shared/`（不会写到 `%TEMP%\_MEI*`） |
| 缺省启动 | `run.bat` = `--no-prompt --open-browser` | frozen 缺省同样 `--no-prompt --open-browser`；直接跑 `python server.py` 仍保持源码交互默认 |

构建步骤见仓库内 `packaging/windows/README.md`（不进四文件 zip）。

## 杀软 / SmartScreen（未签名 exe）

`lan-transfer.exe` **默认未做代码签名**。Windows SmartScreen 可能提示「Windows 已保护你的电脑 / 未知发布者」；Microsoft Defender 或其它杀软也可能对 onefile（启动时解压到 `%TEMP%\_MEI*`）报启发式风险——这是常见误报，**不是**程序在改系统文件。

建议：

1. 只从可信渠道获取，并用发布说明中的 **SHA256** 核对 exe；
2. SmartScreen：点「更多信息」→「仍要运行」；
3. Defender：在「病毒和威胁防护」里允许该文件，或把 exe 所在目录加入排除（仅限你信任的副本）；
4. 首次启动若弹出防火墙，请在**专用网络**允许 `lan-transfer.exe` 入站（不再是 `python.exe`）；
5. onefile 首次启动略慢、体积偏大属正常（自解压到临时目录）；**用户文件应落在 exe 旁 `shared/`**，若看到写入 `%TEMP%\_MEI*` 则构建有误，请停用该副本。

需要企业静默安装或消除 SmartScreen 时，需另行代码签名（本交付不做）。误报极严重时可改用四文件 zip，或后续考虑 onedir 备选（本刀不产）。

## 端口逻辑说明

- **启动预检**：绑定前先做端口探测，失败原因会明确区分——"已被其他程序占用"、"位于 Windows 保留端口段（Hyper-V/WSL 等预留）"、"本机不存在该 IP 地址"
- **显式指定端口**（`--port`）：不可用时直接报错退出，不会擅自更换端口
- **默认端口**：8080 不可用时自动降级到候选端口，终端提示实际端口
- **关闭释放**：Ctrl+C 或进程退出时立即关闭监听 socket 并释放端口，终端打印"端口已释放"

## 命令行启动

```powershell
# 指定 IP
python server.py --host 192.168.1.20

# 同时指定端口
python server.py --host 192.168.1.20 --port 8080

# 监听所有本机 IPv4 网卡并跳过交互询问
python server.py --host 0.0.0.0 --port 8000

# 指定共享目录
python server.py --host 0.0.0.0 --shared-dir "D:\Videos"

# 启用访问口令（也可用环境变量 LAN_TRANSFER_PIN）
python server.py --host 0.0.0.0 --pin 1234

# 主人口令 + 只读访客口令
python server.py --host 0.0.0.0 --pin 1234 --guest-pin 5678

# 共享文件保留 7 天后按入库时间自动删除（默认关；会删用户文件）
python server.py --host 0.0.0.0 --ttl-days 7
```

注意：`--host` 必须是当前电脑实际拥有的 IP 地址，或使用 `0.0.0.0`。不能填写另一台电脑的 IP。

## 功能

- **可选访问口令**：`--pin` / `LAN_TRANSFER_PIN`；未设置则与现在一样无口令；启用后未验证不能列文件 / 上传 / 下载 / 预览 / 剪贴板
- **文件传输**：上传（点击 / 拖放 / **Ctrl 或 ⌘ + V 粘贴** / 多文件队列）、下载、删除，带进度与队列状态显示；文件列表支持勾选批量下载 / 删除；**超过 32 MiB 的文件下载走 Range 分片、可断点续传**（下载中再点「暂停」，再点「继续」；刷新页面后再点下载也从断点续。localhost 等安全上下文用「另存为」直接写盘，局域网 http 访问时分片暂存在浏览器 IndexedDB、下满后保存；超过 2 GiB 或浏览器不支持时回退浏览器自带下载）
- **粘贴上传**：在页面任意非输入区域按 `Ctrl+V`（macOS `⌘V`）即可上传剪贴板中的文件与截图
  - 支持一次粘贴多个文件（资源管理器 / Finder 中多选复制的文件），保留原始文件名与 MIME 类型
  - 截图类条目浏览器只给 `image.png` 这类通用名，会自动重命名为 `截图-20260902-084900.png`，避免连续粘贴互相覆盖
  - **重名避让**：粘贴的文件名若已存在且大小不同，自动改名为 `名称 2.ext`，不会静默覆盖已有文件；同名同大小则保持原名，交给服务端秒传判定
  - 剪贴板为纯文本 / 空内容时不上传，只提示；在文本框、输入框内的粘贴保持浏览器原生行为，不受影响
  - 粘贴后立即在上传区下方展示清单（文件名 + 大小），随后由进度条接管（文件名 + 百分比 + 已传 / 总量 + 速度 + 剩余时间）
  - **兼容性**：桌面 Chrome / Edge / Firefox / Safari 均支持；iOS Safari 只在可编辑元素上弹「粘贴」菜单，因此触屏端额外提供"粘贴"按钮（聚焦隐藏捕获层后长按选择「粘贴」）。不支持的浏览器会提示改用点击 / 拖放
- **断点续传**：上传按分片进行（大文件自动放宽分片），每片落盘即持久；中断（断网 / 刷新页面 / 关服务）后重选同一文件，自动从服务端已收到的偏移量继续，不重传已传部分
- **传输稳定性**：失败指数退避自动重试（重试前先向服务端核对真实偏移，防止数据错位）、每片可选 CRC32 校验（首片实测吞吐，过慢自动关闭）、上传前磁盘剩余空间预检、暂停 / 继续按钮
- **大文件支持**：HTTP/1.1 长连接（单连接连续发片，吞吐翻倍）、分片大小随文件体积自适应（256 KiB – 16 MiB，服务端上限 128 MiB）、流式落盘不占内存、磁盘预检提前报错而非传一半失败
- **同名文件处理**：同名同大小同修改时间的文件自动"秒传"跳过；需要覆盖时，再次选择同一文件上传即会强制重新传输替换
- **文件名安全**：Windows 保留设备名（CON/NUL/COM1 等）与以点、空格结尾的文件名会被拦截或自动清洗，避免落盘后改名导致续传错位
- **上传垃圾清理**：未完成的上传临时分片由服务端定期清扫（超过 7 天未活动的自动删除），服务长期常驻也不会悄悄占满磁盘
- **共享文件自动过期（可选）**：`--ttl-days N` / `LAN_TRANSFER_TTL_DAYS`；默认关。按入库时间删除共享文件（会删用户文件）；与上方分片 7 天扫互不相干；隐藏文件与剪贴板库不删
- **剪贴板同步（历史记录）**：手机与电脑之间传递文本、链接、口令，每条都有据可查
  - 输入内容 → 点「发送」或按 **Enter**（`Shift + Enter` 换行；中文输入法选词的那次 Enter 不会误发）→ **输入框立即清空**，内容出现在历史记录最上方，所有设备 3 秒内自动可见（无需手动拉取）
  - **来源 IP**：每条记录标注发送设备的 IP（`127.0.0.1` 显示为「本机」），一眼看出是谁发的
  - **点击记录直接预览**：点文本或图标弹出完整内容预览（长文本、多行命令、整段 JSON 不再被列表截成两行），预览内可直接「复制」；弹层与文件预览共用同一套
  - **单条操作**：每条右侧「复制」「删除」，与文件区的「下载 / 删除」同一套按钮规范
  - 历史最多保留 50 条，同一台设备连发相同内容只刷新时间、不重复占位
- **文件预览**：图片 / 视频 / 音频 / PDF 直接内置播放；压缩包（zip）展示目录树
- **文档排版预览**：`.docx` 渲染为带格式的网页（标题层级、加粗 / 斜体 / 下划线、对齐、表格、项目符号与编号列表）；`.xlsx` 渲染为表格；`.pptx` 按幻灯片分块展示。全部在服务端用标准库解析，**零第三方依赖**，旧版 `.doc/.xls/.ppt` 提示下载
- **文件列表**：**最新内容置顶**——刚传完的文件排在最前面，已有文件的相对顺序保持稳定，不按文件名 / 大小 / 类型 / 文件自身修改时间重排。传输先后顺序由服务端记录在 `shared/.file-order.json`（隐藏文件，不在列表中显示），服务重启、刷新页面、跨设备都保持一致；直接拷进 `shared/` 目录、没有传输记录的文件按修改时间倒序排在后面。删除文件时同步移除其顺序记录
- **中文命令行日志**：每条请求打印为「时间 + 来源 IP + 中文动作 + 中文状态」，例如 `[14:49:24] 192.168.1.5 - 下载文件「会议记录.txt」 → 200 成功`，未知路由原样回退为 `METHOD /path`，不影响请求本身
- **传输过程顺序稳定**：多文件上传时每传完一个就刷新一次列表，新文件出现在顶部，已在列表中的文件相对位置不发生任何变动；文件序号、进度、状态与重试结果的显示均不受刷新影响
- **加载性能**：页面带 ETag 协商缓存（内容未变返回 304，不重传 86KB 页面）、文本响应 gzip 压缩（约 -70% 传输体积）、favicon 内联零请求、首屏四个接口并行加载、列表内容未变化时跳过 DOM 重建

## 文件位置

默认共享文件保存在程序目录下的 `shared` 文件夹中。上传同名文件时，新文件会替换旧文件。剪贴板历史保存在 `shared/.clipboard-history.json`（隐藏文件，不在文件列表中显示）；旧版本的 `shared/.clipboard.txt` 会在首次读取时自动迁移为一条历史记录，迁移后原文件被删除。

## iOS 微信文件传电脑（重要机制说明）

iOS 沙盒限制：微信里的文件要离开微信，**必须先经过系统"文件"App 中转一次**（"用其他应用打开"→"文件"），无法完全绕过。Safari 也不会出现在"用其他应用打开"列表里——那是给文件选接收 App 的面板，Safari 不是文件接收 App。

中转后可用**快捷指令**一键上传（一次配置）：

1. "快捷指令"App → 新建 → 开启"在共享表单中显示" → 类型勾选"文件"
2. 动作"接收任何输入"（文件）→ 动作"URL" 填 `http://<电脑IP>:<端口>/upload?filename=` + 文件名变量（端口以终端启动提示为准）→ 动作"获取 URL 内容"（POST，请求体选文件）
3. 命名为"传到 PC"

> 注意：快捷指令走的是整包 `/upload`，单个文件**超过 32 MiB 会被拒绝**（返回 413 提示）；大文件请在 iPhone 上用 Safari 打开网页上传（自动分片、可续传）。

使用：微信 → 用其他应用打开 → 文件 → 在"文件"App 中长按该文件 → 共享 → "传到 PC" → 自动上传到电脑 `shared/`。

## Windows 防火墙

第一次启动时，如果 Windows 弹出防火墙提示，请只在可信的"专用网络"中允许访问。若其他设备无法打开页面，请确认：

1. 两台设备在同一局域网或 Wi-Fi 下；
2. 访问的是终端显示的局域网地址，而不是 `127.0.0.1`；
3. 路由器未开启客户端隔离；
4. Windows 防火墙允许 Python（四文件）或 `lan-transfer.exe`（单文件包）接收入站连接。

## HTTP 接口（开发者参考）

- `GET  /` — 传输页面
- `GET  /api/files` — 文件列表 `{files:[{name, size, date}], filesEpoch, latestName}`（最新置顶；`filesEpoch` 随上传/删除变化，前端轮询感知「有新文件」轻提醒；`latestName` 为列表首项或 null）
- `GET  /download/<name>` — 下载文件（attachment，支持 `Range` / `If-Range`，带强 `ETag` + `Last-Modified`；文件被替换后旧 ETag 的 If-Range 回 200 整包）
- `POST /api/download-zip` — 多选打包下载，body `{"names":["a.txt","photos/b.jpg"]}`；流式 `application/zip`；路径前缀保留；缺文件整请求失败；上限 500 个 / 未压缩合计 2 GiB；guest 可下；不对 zip 做 Range
- `GET  /preview/<name>` — 预览文件（inline，支持 Range，视频可拖动进度条）
- `GET  /preview/doc/<name>` — 将 `.docx/.xlsx/.pptx` 渲染为带格式的 HTML 页面（供 iframe 展示排版）；其他格式返回提示页
- `GET  /api/archive/list?name=<zip>` — 列出 zip 压缩包内容树 `{supported, entries:[{path,size,dir}]}`；非 zip 返回 `{supported:false}`
- `GET  /api/doc/text?name=<docx|xlsx|pptx>` — 提取 Office 文档纯文本 `{supported, text}`；旧版 .doc/.xls/.ppt 或不支持的格式返回 `{supported:false}`（纯文本兜底接口，排版预览请使用 `/preview/doc/`）
- `POST /upload?filename=<name>` — 整包上传（请求体为原始字节，一次性整体上传）；**仅建议小文件 / 脚本使用，超过 32 MiB 直接拒绝（413）**，大文件请用下方分片 API（网页上传已自动分片、可断点续传）
- `POST /api/upload/init` — 创建 / 恢复分片上传会话，body `{"name","size","lastModified","sessionId?","force?"}`，返回 `{sessionId, offset, exists, chunkSize, maxChunkSize}`；带 `sessionId` 即查询断点，`exists:true` 表示服务端已有同名同大小文件（秒传），`force:true` 跳过秒传强制覆盖；**续接**：不带或带失效 `sessionId` 时，服务端按 name+size+lastModified 指纹复用未完成会话并返回已传 `offset`（响应 `resumed`/`resumedBy`=`"sessionId"|"fingerprint"|null`），`fresh:true` 丢弃旧进度新开
- `POST /api/upload/chunk?sessionId=<id>` — 追加一个分片，header `X-Upload-Offset`（起始字节）、可选 `X-Chunk-CRC32`（hex 校验，失败自动回滚该片）；偏移不连续返回 409 并附服务端偏移
- `POST /api/upload/complete?sessionId=<id>` — 结束会话，把临时分片落为正式文件
- `GET  /api/upload/status?sessionId=<id>` — 查询已接收偏移量（重试前核对用）
- `DELETE /api/upload/session?sessionId=<id>` — 放弃会话并删除临时分片
- `POST /delete` — 删除文件，body `{"filename": "名称"}`
- `GET  /api/clipboard` — 返回历史记录 `{items: [{id, text, ip, time}], seq, text, updated}`（`text`/`updated` 等价于最新一条，保留给旧客户端）；支持 `If-None-Match`，内容未变返回 304
- `POST /api/clipboard` — 追加一条历史，body `{"text": "内容"}`；单条上限 100000 字符，内容为空返回 400
- `DELETE /api/clipboard?id=<id>` — 删除单条历史（不存在返回 404）
